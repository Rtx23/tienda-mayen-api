SMARTSTORE

Sistema de Gestión Inteligente para Tiendas Pequeñas

Tecnologías:
Java
Spring Boot
Maven
JUnit
MockMvc
Postman
Git
GitHub

Arquitectura:
Controller → Service → Repository

Ejecutar:
mvn spring-boot:run

API:
http://localhost:8080/api/productos

Endpoints:
POST   /api/productos
GET    /api/productos
GET    /api/productos/{id}
PUT    /api/productos/{id}
DELETE /api/productos/{id}

Tests:
mvn test
